# This project uses the Bass Diffusion Model to explore the potential global adoption of Figure AI's Figure 03 humanoid robot, using historical industrial robot installations as a reference.

## Project Files
data/ – dataset of annual industrial robot installations worldwide
img/ – plots generated during the analysis
report_source.Rmd – source code and analysis
report_source.pdf – completed report

## Running the Analysis
1. Open report_source.Rmd in RStudio.
2. Install the required R packages: ggplot2, ggpubr, knitr, diffusion, and dplyr.
3. Knit the file to generate the report.

The analysis compares two methods for estimating Bass Model parameters and examines adoption under three market scenarios.
